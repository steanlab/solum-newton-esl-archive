# Solum Newton ESL Archive

Фотографии плат, сведения о SWD-подключении электронных ценников Solum Newton.

## Цель

- Зафиксировать аппаратные ревизии ESL-меток.
- Документировать SWD-площадки, маркировку MCU и интерфейс дисплея.

## Поддерживаемые платы

`tags/EL022F3WRA-nRF52811/` Solum Newton 2.2" - nRF52811-QFAA - заводской бэкап в ZIP

`tags/EL022F3xxx-EFR32BG22C222WG/` Solum Newton 2.2" - EFR32BG22C222WG - бэкапа нет

`tags/EL016F5W4C-EFR32BG22C222WG/` Solum Newton 1.6" - EFR32BG22C222WG - бэкапа нет

## Инструменты

- Raspberry Pi Pico с `debugprobe_on_pico.uf2`
- FTDI232
- SWD: SWCLK, SWDIO, GND
- OpenOCD
- Silicon Labs Simplicity Commander
- OpenEPaperLink firmware
